# BreatheWise
### AI-Powered Winter Smog and Air Pollution Assistant

Report. Understand. Breathe Better.

BreatheWise is a GenAI-powered assistant that helps families
and communities navigate urban air pollution through
personalized recommendations, indoor air quality guidance,
low-emission routines and environmental impact insights.

## Technology
- React
- TypeScript
- Google Gemini
- Firebase
- Google AI Studio
